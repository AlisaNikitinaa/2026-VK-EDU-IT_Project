## 1. DDD — Доменные зоны
## 1.1 Обучение (Learning)

**Описание:**  ядро платформы — управление курсами, уроки, домашние задания, тесты.
**Сущности:**  Course, Lesson, Assignment, Test, Grade.  
**Глоссарий:**
+ **Course** - курс (например, «Математика для ЕГЭ»).
+ **Lesson** - урок в составе курса (видеолекция, текст, интерактив).
+ **Assignment** - домашнее задание к уроку.
+ **Test** - тест для проверки знаний (промежуточный, итоговый).
+ **Grade** - оценка за задание/тест.

**Ключевые функции:** просмотр уроков, выполнение заданий, прохождение тестов, отслеживание прогресса.

___

## 1.2 Пользователи (User Management)

**Описание:** регистрация, профили учеников, родителей, преподавателей.  
**Сущности:** Student, Parent, Teacher, Role, Profile.  
**Глоссарий:**
+ **Student** - ученик, проходящий курсы.
+ **Parent** - родитель, отслеживающий прогресс ребёнка.
+ **Teacher** - преподаватель, ведущий курсы.
+ **Role** - роль пользователя (ученик, родитель, преподаватель, админ).
+ **Profile** - профиль пользователя с личными данными.  

**Ключевые функции:** регистрация, авторизация, управление профилями, настройка уведомлений.

___

## 1.3 Прогресс и аналитика (Progress & Analytics)

**Описание:** отслеживание успеваемости, генерация отчётов, аналитика эффективности обучения.  
**Сущности:** Progress, Report, Metric, Dashboard.  
**Глоссарий:**  
+ **Progress** - прогресс ученика по курсу (проценты, завершённые уроки).  
+ **Report** - отчёт об успеваемости (для ученика, родителя, преподавателя).  
+ **Metric** - метрика обучения (время на урок, количество попыток теста).  
+ **Dashboard** - панель аналитики для администратора.  

**Ключевые функции:** визуализация прогресса, отчёты, анализ метрик, рекомендации курсов.

___

## 1.4 Оплата и подписки (Payments & Subscriptions)

**Описание:** управление тарифами, подписками, платежами.  
**Сущности:** Plan, Subscription, Payment, Invoice.  
**Глоссарий:**  
+ **Plan** - тарифный план (базовый, премиум, индивидуальный).
+ **Subscription** - активная подписка ученика.
+ **Payment** - платёж за курс/подписку.
+ **Invoice** - счёт на оплату.  

**Ключевые функции:** выбор тарифа, оформление подписки, обработка платежей, генерация счетов.

___

## 1.5 Поддержка и сообщество (Support & Community)

**Описание:** общение, поддержка, форумы, чаты.
**Сущности:** Ticket, Forum, Chat, Review.
**Глоссарий:**
+ **Ticket** - заявка в службу поддержки.
+ **Forum** - форум для обсуждения курсов.
+ **Chat** - чат с преподавателем/куратором.
+ **Review** - отзыв о курсе/преподавателе.

**Ключевые функции:** обработка обращений, модерация чатов, сбор отзывов, рейтинги курсов.

## 2. BDD — Критический путь: прохождение урока и сдача теста

**Сценарий успеха:**  

**Дано:**  
+ ученик зарегистрирован и подписан на курс «Математика для ЕГЭ»;
+ урок «Квадратные уравнения» доступен для просмотра;
+ тест по уроку ещё не пройден.  

**Когда:**  
+ ученик открывает урок и смотрит видеолекцию;
+ переходит к домашнему заданию и выполняет его;
+ сдаёт тест по уроку.  

**Тогда:** 
+ урок отмечается как просмотренный в прогрессе курса;
+ выполненное задание проверяется автоматически/преподавателем;
+ результаты теста отображаются в отчёте с оценкой и комментариями;
+ прогресс ученика обновляется (процент завершения курса);
+ ученик получает уведомление о завершении урока и результатах теста.  
___

**Сценарий отказа:**  

**Дано:**
+ ученик пытается сдать тест, не просмотрев урок;
+ тест заблокирован до просмотра обязательного материала.  

**Когда:**  
+ ученик нажимает «Сдать тест».  

**Тогда:**  
+ всплывает сообщение: «Пожалуйста, сначала просмотрите урок»;
+ кнопка «Сдать тест» остаётся неактивной до просмотра урока;
+ система направляет ученика к материалу урока.

## 4. API-First — JSON-контракты

**GET /api/courses — получить список курсов**  

**Запрос:**


```
GET /api/courses?category=math&level=advanced
```

**Успешный ответ (200):**

```
{
  "courses": [
    {
      "id": 1,
      "name": "Математика для ЕГЭ (продвинутый уровень)",
      "category": "math",
      "level": "advanced",
      "teacher": "Иванов И.И.",
      "price": 990,
      "rating": 4.8,
      "lessons_count": 20
    }
  ],
  "total": 1
}
```

**Ошибка (400):**

```
{
  "error": "invalid_param",
  "message": "level must be basic, intermediate or advanced"
}
```
______

**POST /api/assignments/submit — отправить решение задания**  

**Запрос:**

```
{
  "assignment_id": 42,
  "solution": "x = 5, y = 3",
  "file_url": "https://storage.example.com/files/solution_42.pdf"
}
```

**Успешный ответ (200):**

```
{
  "submission_id": 101,
  "status": "pending",
  "submitted_at": "2023-10-05T10:30:00Z"
}
```

**Ошибка (400):**

```
{
  "error": "validation_error",
  "message": "solution is required"
}
```
